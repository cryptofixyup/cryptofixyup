# Repository Security & Architecture Review

**Fixed price: £150 GBP**

Independent, evidence-led review of one software repository at one agreed commit or branch.

For founders and small engineering teams who need a clearer view of repository-level security, architecture, dependency, and CI risks before a release, handover, or technical decision.

## What is included

The review examines the agreed repository revision and relevant:

- Source code and security-sensitive code paths
- Dependency manifests and lockfiles
- CI/CD workflows and permission boundaries
- Configuration and secret-handling patterns visible in the repository
- Tests and regression coverage
- Documented architecture and trust boundaries

The exact review areas and exclusions are recorded in the report.

## What you receive

1. **Executive summary** — concise overall assessment and key limitations.
2. **Prioritized findings** — evidence-linked observations, impact, and recommended actions.
3. **Evidence classification** — observed facts separated from inference and unknowns.
4. **Verification record** — commands/checks actually run, with results; checks not run are identified.
5. **Next actions** — a prioritized list for the engineering team.

## Scope and boundaries

- One repository and one agreed branch/commit.
- Read-only review unless a separate implementation scope is agreed.
- No production credentials are required for initial scoping.
- No code remediation is included in the £150 fee.
- Remediation and re-verification are quoted separately.

This service is not a penetration test, formal security audit, compliance certification, or guarantee that every vulnerability will be found. A source review cannot establish the security of infrastructure, account settings, secrets, runtime behavior, or systems that were not made available for inspection.
